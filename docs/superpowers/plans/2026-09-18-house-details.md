# House Details Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the estate's houses the details a Dutch terrace has: windows one or two cells wide, garage doors in the fronts that have garages, floor-to-ceiling glass at some backs, gable ends that meet the roof instead of climbing in teeth, and dakkapellen on the roofs.

**Architecture:** Three of the five are PATCHES on surfaces that already exist, decided per dwelling by flags the importer writes into the `row` recipe (`garage`, `glazing`) and realised by `Openings` styles; one is four new SURFACES per flagged dwelling (`dormer`), generated in a fixed place in the order; one is DRAWING only — the client fills the tooth above every gable column with a box and a wedge in the gable's material, hidden with the cell they sit on. Nothing touches the `building` recipe, so the four hand-made worlds' pieces do not move; `geleen` is re-imported once.

**Tech Stack:** Rails 8.1, plain Ruby under `app/models/game/`, three.js 0.170 (vendored), Rapier unchanged. Minitest; system tests in headless Chrome.

**Spec:** `docs/superpowers/specs/2026-09-18-house-details-design.md`. It builds on `2026-09-18-how-buildings-look-design.md` (styles, palettes, hedges) and `2026-09-18-geleen-two-islands-design.md` (the `row` recipe and its order).

## Global Constraints

- **Every tuning number lives in Ruby.** Dormer size and setback, garage-door width, glazing width, the proportions the importer flags at: all Ruby constants or recipe fields. The client's only new constant is the wedge's unit shape.
- **Piece indices are the contract.** Openings change patches, never grids: `generator_test`'s worked example (23 surfaces, 1553 pieces, its offsets) and `row_test`'s unflagged pair (29 surfaces, 840 pieces) and annex example (34 surfaces, 921) stay exactly as they are. Dormer surfaces are appended in step 5b (right after the dwelling's roof section) and only when a dwelling is flagged, so an unflagged row keeps its numbering byte for byte. The `geleen` fixtures are regenerated by `bin/rails geleen:import` and the dev database re-seeded with `bin/rails geleen:seed`, never `db:seed`.
- **`:classic` is untouchable.** `Openings.new(seed: 7).for_wall(edge: 0, storey: 1, cols: 12, rows: 3)` must still return glass at columns `[1, 3, 5, 7, 9, 11]`, row 1; the `building` recipe's door stays three cells of timber under a steel lintel.
- **Draw calls track materials, never buildings.** Gable caps add instances to pools that exist and ONE new shape pool per gable material (`brick#wedge`), allocated once from `Building.countMaterials`. `street_test` (street ≤ one house) and `building_test` (under 45 draws) stay green.
- **The importer decides, the generator realises.** Flags come from `seed` and the dwelling index through a small deterministic hash, subject to the geometric conditions the spec states; the generator never draws a random number.
- **Hedges, rubble and the collapse rule are untouched.** Dormer surfaces carry `storey: row.storeys` and the dwelling's `bay`, like a roof, so they fall with it and weigh as load; nothing about `Collapse` changes.
- **Testing discipline** as before: the named file for what changed; `bin/rails test` and `bin/rubocop` before each commit; no full system suite between tasks; the machine lock; the dev server on port 3100 stays up; geleen assertions about simulated events use `wait_for_simulated`. `node --input-type=module --check < file` with node under `~/.local/share/mise/installs/node/*/bin`.
- **Commits** end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Decisions taken here that narrow the spec

- **Window runs draw their widths from a small integer hash of the seed, edge, storey and run index**, two cells when the hash is even, one when odd — roughly half and half. The spec says "drawn from the seed per run"; this is the draw.
- **The garage door is on the side of the front AWAY from the front door**, one pier between, three cells wide, shrinking to two if the face has no room for three, and absent under two. On a six-column front that puts the door at column 1 (or 4) and the garage at 3..5 (or 0..2), which is the layout of a 1980s "garage in de woning".
- **Rear glazing takes the place of that storey's windows on that face**: one glass patch, three cells wide when the face has five or more columns and two below that, spanning every row, starting at a seeded column that keeps one pier at each end.
- **A dormer's front is glass with a plaster return at each end column**, its cheeks plaster, its top steel. Dutch dakkapellen are white-clad boxes with a window the width of the box; plaster is the light flat material we have, steel the zinc.
- **Caps for a column with no standing cell at all** (the eaves corners, where the roof line is lower than one row) are attached to the nearest column toward the apex that has one, so they go when that column's top goes rather than hanging at the eaves after a collapse.
- **The importer flags dormers only on gable rows with rise ≥ 2.5 m and room under the ridge**, garages only on `house` rows without a garage box and fronts of six or more cells, glazing anywhere; proportions 45 % / 33 % / 35 %.

Add the private methods (keep `sill`, `door`, `door_span`, `front_window` as they are; replace `window` with `window_patch`):

```ruby
        # One patch over `col0..col1`, `tall` rows when there is a course below and above
        # them, one row otherwise. A two-row window in a two-row storey is a hole.
        def window_patch(col0, col1, rows)
          row = sill(rows)
          height = rows >= style[:tall] + 2 ? style[:tall] : 1
          Surface::Patch.new(col0: col0, row0: row, col1: col1, row1: row + height - 1, material: :glass)
        end

        # The garage door, on the side of the front away from the front door: three cells
        # when they fit before the last column, two when only two do, none otherwise.
        def garage_door(cols, rows, door)
          return nil if cols < GARAGE_MIN_COLS

          if door.col0 < cols / 2
            first = door.col1 + 2
            last = [ first + GARAGE_WIDTH - 1, cols - 1 ].min
          else
            last = door.col0 - 2
            first = [ last - GARAGE_WIDTH + 1, 0 ].max
          end
          return nil if last - first + 1 < 2

          Surface::Patch.new(col0: first, row0: 0, col1: last, row1: [ GARAGE_ROWS, rows ].min - 1, material: :door)
        end

        # One glass patch from floor to ceiling, its start drawn from the seed so a terrace
        # of glazed backs is not a row of identical ones, a pier kept at each end.
        def glazing(cols, rows)
          width = cols >= 5 ? GLAZING_WIDTH : GLAZING_NARROW
          room = cols - 2 - width
          first = 1 + (room.positive? ? hash(BACK_EDGE, 0, 0) % (room + 1) : 0)
          Surface::Patch.new(col0: first, row0: 0, col1: first + width - 1, row1: rows - 1, material: :glass)
        end

        # Windows as runs: from a seeded start, each one or two cells wide by the seed,
        # one pier between, never reaching the last column. `[[col0, col1], …]`.
        def window_runs(edge, storey, cols)
          case style[:windows]
          when :runs
            return [] if cols < 3

            runs = []
            col = 1 + ((seed + edge * 3 + storey) % 2)
            k = 0
            while col <= cols - 2
              width = hash(edge, storey, k).even? ? 2 : 1
              width = 1 if col + width - 1 > cols - 2
              runs << [ col, col + width - 1 ]
              col += width + 1
              k += 1
            end
            runs
          else
            window_columns(edge, storey, cols).map { |col| [ col, col ] }
          end
        end

        # A small integer hash of the seed and a few salts, for the per-run and per-face
        # draws. Deterministic, like everything about a recipe has to be.
        def hash(a, b, c)
          (seed * 2_654_435_761 + a * 40_503 + b * 9973 + c * 7919) % 1_000_003
        end
```

      # box, white cheeks and a zinc top. Everything here is metres in the row's frame and
      # decided by four constants, so a dormer on a 1987 terrace is the size a 1987 dormer
      # is and never a random one.
      DORMER_WIDTH = 3.0
      DORMER_HEIGHT = 1.5
      # How far in from the eaves line the front face stands.
      DORMER_SETBACK = 1.0
      # The top has to meet the roof this far below the ridge, or the dormer is a second
      # ridge. The importer checks the same sum before it flags a dwelling.
      DORMER_CLEARANCE = 0.5
      DORMER_MIN_WIDTH = 1.5

      # 5b. Four surfaces, or none: the front (glass, a plaster return at each end column),
      # two cheeks (plaster, rectangles whose lower rear corner lies inside the roof and is
      # never seen) and the flat top (steel). The front's foot is ON the roof plane, at
      # `eaves + rise * setback / run`; the top is DORMER_HEIGHT above it, and the roof
      # reaches that height `height * run / rise` further back, which is where the cheeks
      # and the top end. Above every storey and in the dwelling's bay, like its roof, so
      # it falls with the dwelling.
      def self.dormer(row, d, i)
        return [] unless d.dormer && row.roof == "gable" && row.rise.positive?

        run = row.depth / 2.0
        width = [ DORMER_WIDTH, d.width - 2.0 ].min
        return [] if width < DORMER_MIN_WIDTH

        depth = DORMER_HEIGHT * run / row.rise
        return [] if DORMER_SETBACK + depth > run - DORMER_CLEARANCE

        x0 = d.x0 + (d.width - width) / 2.0
        x1 = x0 + width
        z_front = row.z0 + DORMER_SETBACK
        y_base = row.eaves + row.rise * DORMER_SETBACK / run
        y_top = y_base + DORMER_HEIGHT
        cols = Walls.cells(width, row.cell)
        rows = [ Walls.cells(DORMER_HEIGHT, row.cell), 1 ].max
        deep = Walls.cells(depth, row.cell)
        returns = cols >= 3 ? [ 0, cols - 1 ].map { |c| Surface::Patch.new(col0: c, row0: 0, col1: c, row1: rows - 1, material: :plaster) } : []

        front = Surface.new(kind: :wall, storey: row.storeys, material: Materials.fetch(:glass), origin: Vector3.new(x0, y_base, z_front),
                            u: EAST, v: UP, width: width, height: DORMER_HEIGHT, cols: cols, rows: rows, thickness: Walls::THICKNESS,
                            patches: returns, seed: row.seed + 300 + i, bay: i)
        cheeks = [ x0, x1 ].map do |x|
          Surface.new(kind: :wall, storey: row.storeys, material: Materials.fetch(:plaster), origin: Vector3.new(x, y_base, z_front),
                      u: SOUTH, v: UP, width: depth, height: DORMER_HEIGHT, cols: deep, rows: rows, thickness: Interior::PARTITION_THICKNESS,
                      seed: row.seed + 300 + i, bay: i)
        end
        top = Surface.new(kind: :roof, storey: row.storeys, material: Materials.fetch(:steel), origin: Vector3.new(x0, y_top, z_front),
                          u: EAST, v: SOUTH, width: width, height: depth, cols: cols, rows: deep, thickness: Roof::THICKNESS, bay: i)
        [ front, *cheeks, top ]
      end

Create `app/javascript/game/world/gables.js`:

```js
import * as THREE from "three"
import { materialAt } from "game/world/surface"

// The gable ends meet the roof.
//
// A gable is a stair of whole cells, clipped by Roof.clip against the roof line, and the
// stair IS the piece numbering -- Ruby and JavaScript count the same grid, and nothing here
// may change that. What a player sees, though, is a wall that stops short of the roof in
// teeth. So the client fills the tooth above every column's topmost standing cell with two
// extra instances in the gable's own material and tint: a BOX up to the lower of the roof
// line's two heights across the column, and a WEDGE -- a unit right triangular prism, one
// new shape pool per material -- from there to the higher, turned toward the apex. The apex
// column, where the line peaks inside the column, gets two half-width wedges.
//
// Caps are drawing. They are placed at boot, counted into the pools like a heap's chunks,
// hidden when the cell under them breaks and shown when it is restored. They have no
// collider: the tooth was never something a car could hit.

export const WEDGE_SUFFIX = "#wedge"

export function wedgePool(name) {
  return `${name}${WEDGE_SUFFIX}`
}

export function isWedgePool(pool) {
  return pool.endsWith(WEDGE_SUFFIX)
}

// The roof line Roof.clip judges by: a triangle over the gable's width, `1 - |2t - 1|` of
// its height at fraction `t` across.
function lineAt(t, height) {
  return height * (1 - Math.abs(2 * t - 1))
}

// Per column: the topmost standing row (or -1), the box and the wedges that fill the tooth
// above it. `anchorCol` is the column whose top cell the caps go with: the column itself,
// or, for a column with no standing cell at all (the eaves corners), the nearest column
// toward the apex that has one -- so nothing hangs at the eaves after a collapse.
export function gableCaps(surface) {
  const cellW = surface.w / surface.cols
  const cellH = surface.h / surface.rows
  const tops = []
  for (let col = 0; col < surface.cols; col += 1) {
    let top = -1
    for (let row = surface.rows - 1; row >= 0; row -= 1) {
      if (materialAt(surface, row, col) !== "void") { top = row; break }
    }
    tops.push(top)
  }

  const caps = []
  for (let col = 0; col < surface.cols; col += 1) {
    const yK = (tops[col] + 1) * cellH
    const x0 = col * cellW
    const tL = col / surface.cols
    const tR = (col + 1) / surface.cols
    const yL = lineAt(tL, surface.h)
    const yR = lineAt(tR, surface.h)
    const wedges = []
    let box = null

    if (tL < 0.5 && tR > 0.5) {
      // The apex column: the line rises to the peak inside it and falls again.
      const low = Math.min(yL, yR)
      if (low > yK) box = { x0, width: cellW, y0: yK, height: low - yK }
      const base = Math.max(yK, low)
      const half = cellW / 2
      if (surface.h > base) {
        wedges.push({ x0, width: half, y0: base, height: surface.h - base, high: 1 })
        wedges.push({ x0: x0 + half, width: half, y0: base, height: surface.h - base, high: -1 })
      }
    } else {
      const low = Math.min(yL, yR)
      const high = Math.max(yL, yR)
      if (low > yK) box = { x0, width: cellW, y0: yK, height: low - yK }
      const base = Math.max(yK, low)
      if (high > base) wedges.push({ x0, width: cellW, y0: base, height: high - base, high: yR > yL ? 1 : -1 })
    }

    let anchorCol = col
    if (tops[col] < 0) {
      const step = tL < 0.5 ? 1 : -1
      for (let c = col + step; c >= 0 && c < surface.cols; c += step) {
        if (tops[c] >= 0) { anchorCol = c; break }
      }
    }
    caps.push({ col, anchorRow: tops[anchorCol], anchorCol, box, wedges })
  }
  return caps
}

// A unit right triangular prism: x from 0 to 1, y from 0 to 1, z from -0.5 to 0.5; the
// vertical face at x = 1, the slope from (0, 0) to (1, 1), so scaling by (width, height,
// thickness) and placing at a column's left edge fills a tooth that is higher on the right.
// The other way round is the same shape turned half a turn about y.
export function wedgeGeometry() {
  const a = [ 0, 0, -0.5 ], b = [ 1, 0, -0.5 ], c = [ 1, 1, -0.5 ]
  const d = [ 0, 0, 0.5 ], e = [ 1, 0, 0.5 ], f = [ 1, 1, 0.5 ]
  const positions = [
    // back triangle (z = -0.5), facing -z
    ...a, ...c, ...b,
    // front triangle (z = +0.5), facing +z
    ...d, ...e, ...f,
    // bottom (y = 0), facing -y
    ...a, ...b, ...e, ...a, ...e, ...d,
    // vertical face (x = 1), facing +x
    ...b, ...c, ...f, ...b, ...f, ...e,
    // slope, facing (-1, 1, 0)
    ...a, ...d, ...f, ...a, ...f, ...c
  ]
  const geometry = new THREE.BufferGeometry()
  geometry.setAttribute("position", new THREE.Float32BufferAttribute(positions, 3))
  // Metres-along-the-face uv is what the metres chunk computes; a plain uv keeps the
  // fallback path sane for a material with no look.
  const uv = []
  for (let i = 0; i < positions.length; i += 3) uv.push(positions[i], positions[i + 1])
  geometry.setAttribute("uv", new THREE.Float32BufferAttribute(uv, 2))
  geometry.computeVertexNormals()
  return geometry
}
```

  // The caps that make a gable meet the roof: placed once, keyed by the cell they stand on.
  buildCaps(surface) {
    const u = new THREE.Vector3().fromArray(surface.u)
    const v = new THREE.Vector3().fromArray(surface.v)
    const n = new THREE.Vector3().fromArray(surface.n)
    const origin = new THREE.Vector3().fromArray(surface.o).add(this.origin)
    const name = surface.mat
    const cellW = surface.w / surface.cols

    for (const cap of gableCaps(surface)) {
      if (cap.anchorRow < 0) continue
      const index = surface.off + cap.anchorRow * surface.cols + cap.anchorCol
      const entry = this.caps[index] || (this.caps[index] = { pools: [], slots: [], matrices: [] })
      const place = (pool, matrix, cellU, cellV) => {
        entry.pools.push(pool)
        entry.slots.push(this.meshes.add(pool, matrix, this.tintFor(name, index), cellU, cellV))
        entry.matrices.push(matrix.clone())
      }
      if (cap.box) {
        CAP_MATRIX.makeBasis(u, v, n)
        CAP_MATRIX.scale(CAP_SCALE.set(cap.box.width, cap.box.height, surface.t))
        CAP_MATRIX.setPosition(CAP_POSITION.copy(origin).addScaledVector(u, cap.box.x0 + cap.box.width / 2).addScaledVector(v, cap.box.y0 + cap.box.height / 2))
        place(name, CAP_MATRIX, cap.col * cellW, cap.box.y0)
      }
      for (const wedge of cap.wedges) {
        // High on the right: the unit wedge as it is, from the column's left edge. High on
        // the left: the same shape turned half a turn about v, from the right edge.
        if (wedge.high > 0) CAP_MATRIX.makeBasis(u, v, n)
        else CAP_MATRIX.makeBasis(CAP_U.copy(u).negate(), v, CAP_N.copy(n).negate())
        CAP_MATRIX.scale(CAP_SCALE.set(wedge.width, wedge.height, surface.t))
        const edge = wedge.high > 0 ? wedge.x0 : wedge.x0 + wedge.width
        CAP_MATRIX.setPosition(CAP_POSITION.copy(origin).addScaledVector(u, edge).addScaledVector(v, wedge.y0))
        place(wedgePool(name), CAP_MATRIX, cap.col * cellW, wedge.y0)
      }
    }
  }

  showCaps(index, visible) {
    const entry = this.caps[index]
    if (!entry) return
    for (let k = 0; k < entry.slots.length; k += 1) {
      this.meshes.setVisible(entry.pools[k], entry.slots[k], visible, entry.matrices[k])
    }
  }

  // For the tests: how many caps this building placed and how many are showing.
  capReadout() {
    let boxes = 0
    let wedges = 0
    let shown = 0
    for (const entry of this.caps) {
      if (!entry) continue
      for (let k = 0; k < entry.pools.length; k += 1) {
        if (entry.pools[k].endsWith(WEDGE_SUFFIX)) wedges += 1
        else boxes += 1
        if (this.meshes.isVisible(entry.pools[k], entry.slots[k])) shown += 1
      }
    }
    const columns = this.spec.surfaces.filter((s) => s.kind === "gable").reduce((sum, s) => sum + s.cols, 0)
    return { columns, boxes, wedges, shown }
  }
